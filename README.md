# AI 서비스 개발·설계 2026

AI 서비스의 기획, 데이터 설계, 모델 연계, 응용 시스템 구현, 검증 및 배포를 다루는 공개 학습·프로젝트 저장소입니다.

## 홈페이지

- GitHub Pages: https://yuul-jung.github.io/ai_service_dev_design_2026/
- 메인 진입점: [index.html](index.html)

## 운영 기준

- `index.html`은 공개 메인 목차로 사용합니다.
- 개별 문서·실습·캡스톤 페이지는 실제로 파일을 추가한 뒤 메인에서 연결합니다.
- 미작성 자료는 깨진 링크를 걸지 않고 '자료 준비 중'으로 표시합니다. 현재 메인의 모든 항목에 연결된 자료가 있습니다.
- 검증된 자료부터 단계적으로 게시합니다.

## GitHub Pages 활성화

저장소 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**, Branch **main**, Folder **/(root)**를 선택한 뒤 **Save**를 누릅니다. 최초 게시가 끝나면 위 GitHub Pages 주소에서 확인할 수 있습니다.
