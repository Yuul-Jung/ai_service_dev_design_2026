시각언어행동 모델Vision-Language-Action (VLA)

영상·언어 지시·현재 관절 상태를 입력받아 이후 여러 시점의 로봇 행동을 출력하는 모델입니다. 행동 생성이 글처럼 ‘다음 토큰 예측’으로만 이루어지는 것은 아닙니다(p.73).

되먹임Feedback loop

실행한 뒤의 영상과 관절 상태를 다시 받아 다음 행동을 정합니다. 처음 관찰만 쓰면 그 사이 움직인 물체와 바뀐 자세를 반영할 수 없습니다(p.76–77).

3일차의 지도학습과 같은 구조입니다. 입력(관찰한 상태)과 목표(그 뒤에 기록된 동작)를 짝지어 예측과 비교하며 조정합니다. VLA(시각언어행동) 모델은 시각·언어·행동을 함께 다루는 모델이며(p.73), 한 번 관찰한 뒤 앞으로의 여러 동작을 묶어서 만들 수 있습니다(p.74, 행동 묶음).

검증 · 공개 사례 π₀의 구조를 공식 저장소로 확인 일치 보충

  • π₀를 공개한 openpi의 README는 π₀를 “flow 기반 시각-언어-행동 모델(VLA)”이라 하고, 기본 모델 체크포인트를 1만 시간 이상의 로봇 자료로 사전학습했다고 밝힙니다. 이것이 슬라이드의 “π₀는 이 구조를 로봇 자료로 학습한다”(p.73)에 해당합니다.
  • 공식 구성 파일은 모델이 시각언어 모델 부분(gemma_2b)과 행동 전문 부분(gemma_300m)으로 이루어지고, 행동 차원 32(action_dim), 행동 묶음의 길이 50(action_horizon)이 기본값임을 보여 줍니다. 슬라이드의 “시각언어 모델과 상태·행동 처리 부분”(p.73)과 “행동 묶음”(p.74)이 구성 파일의 구조와 같습니다. 슬라이드가 밝히듯 실행 범위와 재관찰 주기는 시스템마다 다릅니다.
  • 슬라이드에 없는 보충: README는 같은 저장소의 π₀-FAST를 “자기회귀(autoregressive) VLA”로, π₀를 “flow 기반”으로 구분합니다. 즉 행동 생성이 글처럼 ‘다음 토큰 예측’으로만 이루어지는 것은 아닙니다. 슬라이드가 설명한 ‘이후 여러 시점의 로봇 행동을 출력’하는 구조는 두 방식에 모두 해당하지만, 행동을 만드는 계산 방식은 모델마다 다릅니다.

주의 · 학습할 때와 사용할 때 (p.74–75)

학습 때는 뒤 행동이 기록에 있고, 사용할 때는 모델이 행동을 만듭니다. 그림(p.75)의 “집게가 물체 쪽으로 접근했다”는 물체를 집었다는 뜻이 아닙니다. 관찰·행동 관계를 나타낸 도식이며 실제 로봇 모델의 실행 결과도 아닙니다. 접근한 뒤 실제로 잡았는지는 실행 뒤의 관찰로 확인해야 합니다.

03되먹임 · 시간과 물리적 제약p.76–77

자료 p.76–77

되먹임: 실행 뒤의 영상과 관절 상태를 다시 받아 다음 행동을 정한다. “처음 관찰만 계속 쓰면 바뀐 자세를 반영할 수 없다.” 관찰과 실행 사이에는 촬영 → 계산·전달 → 실행의 시간이 있어 “그 사이 물체가 움직이면 목표 위치도 달라질 수 있다.” 장치의 조건(팔의 도달 범위·집게 크기·접촉 조건)이 출력한 동작을 실제로 수행할 수 있는 범위를 정한다.

검증 · 관찰과 실행 사이의 지연이 위치에 미치는 영향 (추가 계산 · 설명용 가정값) p.77의 논리 확인 가정값

컨베이어의 물체가 초속 0.20m로 움직이고, 촬영 → 계산·전달 → 실행까지 0.10초가 걸린다면 0.20 m/s × 0.10 s = 0.02 m = 2cm (관찰한 위치와 실행 시점의 실제 위치의 차이) 지연이 0.50초로 늘면 0.20 × 0.50 = 0.10 m = 10cm

관찰한 위치로 정확히 움직여도 그 사이 물체가 이동한 만큼 어긋납니다. 이 때문에 한 번의 관찰로 긴 동작을 밀고 가지 않고 실행 도중 다시 관찰해(되먹임) 목표를 고칩니다. 수치는 원리를 보이기 위한 가정값이며 실제 로봇의 지연이 아닙니다.

08핵심 정리

  • 피지컬 AI의 출력은 장치가 실행할 수치이며, 같은 장면이라도 현재 관절 상태가 입력에 들어가야 필요한 움직임이 정해집니다.
  • VLA 모델은 관찰과 그 뒤의 행동을 짝지어 학습하고(π₀: 1만 시간 이상의 로봇 자료), 행동을 묶음으로 만들 수 있으며, 행동 생성이 항상 ‘다음 토큰 예측’인 것은 아닙니다.
  • 실행한 뒤 다시 관찰(되먹임)해야 하며, 관찰과 실행 사이의 지연과 장치의 도달·접촉 조건이 수행 범위를 정합니다.
  • 자율주행의 수준 구분(감시·인계의 역할)과 한국 법의 부분·완전 구분은 따로 설명하며, 실외이동로봇은 운행계획(통신장애·사고·혼잡 대응)을 포함해 운행안전인증을 받습니다.
  • 자연어로 요청해도 필요한 데이터와 전문 기능이 자동으로 연결되지는 않습니다.
