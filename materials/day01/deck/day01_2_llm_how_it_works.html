보충 · 자료 밖 내용 수식

Attention(Q, K, V) = softmax( Q·Kᵀ / √d ) · V
  • Q·Kᵀ가 질의와 키의 비교(유사도 점수), softmax가 그 점수를 합이 1인 비중으로 바꾸는 단계, V를 곱하는 것이 p.70의 가중합입니다. √d로 나누는 것은 벡터가 길어질 때 점수가 지나치게 커지는 것을 막는 장치입니다.
  • 글을 생성하는 모델은 아직 생성되지 않은 뒤 위치를 보지 못하도록 막고 앞 위치만 참고합니다. 자료 p.69의 “참고할 앞 위치”라는 표현이 이 구조와 맞습니다.
  • 실제 모델은 이런 계산을 여러 개 나란히 수행합니다(멀티헤드 어텐션). 각각이 서로 다른 관계를 잡아내도록 학습됩니다.

19핵심 정리

  • LLM은 글을 토큰 → 번호 → 임베딩으로 바꾸고, 위치 정보와 어텐션으로 문맥을 반영해 다음 토큰의 확률을 계산합니다.

  • 문맥은 이번에 실제로 전달된 입력이며, 화면의 대화 기록과 같지 않습니다.
  • 능력은 사전학습 → 지도 미세조정 → 정렬로 형성되고, 모두 매개변수를 바꾸는 별도의 학습입니다.
  • 자료를 입력에 넣거나 서비스가 저장했다가 다시 넣는 것은 학습이 아닙니다. 같은 답이 나와도 경로가 다릅니다.
