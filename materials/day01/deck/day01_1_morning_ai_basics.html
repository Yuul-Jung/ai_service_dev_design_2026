1일차 오전 · 09:00–12:00

AI는 무엇을 내놓고, 어떻게 만들어지는가

스팸 메일 분류와 답장 생성이라는 한 쌍의 예로 AI의 결과 형태, 규칙과 학습, 모델·매개변수·학습·추론을 구분하고, 모델이 서비스 안에서 도구·에이전트와 함께 쓰이는 방식까지 정리합니다.

쪽 p.1–50예제 스팸 메일계산 검증 3건 일치탐구 질문 10묶음

머신러닝Machine Learning

사람이 판별 조건을 쓰지 않고, 정답이 붙은 자료와 예측을 비교하며 판별에 쓰는 수치를 조정하는 방식입니다(p.21).

추론Inference

학습으로 정해진 매개변수를 그대로 쓰며 새 입력의 결과를 계산하는 단계입니다(p.28). 이때 매개변수는 바뀌지 않습니다.

이 구간의 축은 둘입니다. 무엇을 내놓는가(분류·수치 예측·생성)와 어떻게 만드는가(규칙·학습)를 섞지 않고, 학습은 값을 바꾸고 추론은 값을 쓴다는 구분을 세웁니다.

01AI의 범위와 결과의 형태p.15–18 · p.30–31

AI를 이해하는 첫 질문은 “무슨 결과가 필요한가?”입니다. 결과의 형태가 정해져야 그 기능을 어떻게 만들지 고를 수 있습니다.

자료 p.17

인공지능: 인식·추론·문제 해결 등 지능과 관련된 기능을 컴퓨터로 구현하는 기술과 연구 분야. AI는 대화형 서비스만을 뜻하지 않는다.

분류 · 범주를 고른다

받은 메일 “신청한 강좌는 월요일에 시작합니다.”
선택지 일반 / 스팸 → 결과 일반

생성 · 내용을 구성한다

요청 “참석이 어렵다고 답장하기”
→ “월요일에는 참석이 어렵습니다. 다른 일정으로 신청할 수 있나요?”

자료 p.18

“차이는 결과의 형태다. 분류는 범주, 생성은 요청에 맞게 구성한 내용이 나온다.”

결과 형태 (p.30)입력 → 결과교육 업무의 예 (p.31)
분류메일 → 일반 / 스팸문의 메일 → 신청·결제·일정
수치 예측과거 신청 기록 → 다음 달 예상 인원과거 문의 기록 → 다음 주 문의량
생성문의와 안내문 → 새 답장교육 안내와 질문 → 답변 초안

주의 · 두 페이지의 분류 방식이 다르다

p.17은 “과거 자료로 수요를 예측”을 판별하는 AI 아래에 두지만, p.30은 수치 예측을 분류와 별도의 결과 형태로 나눕니다. p.17의 ‘판별’은 “생성하지 않는 AI”를 넓게 묶은 표현으로 읽으면 두 페이지가 충돌하지 않습니다. 가르칠 때는 p.30의 세 갈래(분류·수치 예측·생성)를 기준으로 삼는 편이 혼동이 적습니다.

보충 · 자료 밖 내용 용어

영어로는 분류 classification, 수치 예측 regression(회귀), 생성 generation이라고 부릅니다. p.49의 탐구 질문 “수치 예측을 다루는 회귀는 무엇인가?”의 답이 바로 이 수치 예측입니다.

p.30의 “하나의 모델이 여러 작업을 수행할 수도 있다”는 실제로 흔합니다. 생성형 언어 모델에 “일반 또는 스팸 중 하나로만 답하라”고 지시하면, 생성 모델이 분류 결과를 내놓습니다. 결과의 형태는 모델의 종류가 아니라 요청과 출력 형식으로도 정해질 수 있습니다.

02규칙 기반 분류와 머신러닝p.19–21

같은 분류 기능도 두 가지 방법으로 만들 수 있습니다. 차이는 판별 방법을 누가 정하느냐입니다.

규칙을 직접 작성자료로 학습 (머신러닝)
준비사람이 조건을 만든다메일과 올바른 분류를 모은다
예“무료”가 있으면 스팸분류된 여러 메일
틀렸을 때새 유형을 놓치면 조건을 수정예측과 분류값을 비교하며 판별에 쓰는 수치를 조정
자료 p.20 · 규칙의 한계

“무료”가 있으면 스팸 → “신청한 무료 강좌 안내”를 스팸으로 오판

“무료”가 없으면 일반 → “당첨금 수령 링크”를 일반으로 오판

왜 규칙이 틀리는가
규칙은 사람이 떠올린 표면 단서 하나에 기댑니다. 같은 단어가 정상 메일에도 나오고(무료 강좌), 스팸은 그 단어를 피해서 쓰입니다(당첨금 링크). 규칙을 늘릴수록 예외도 늘어납니다.
머신러닝은 무엇을 바꾸는가
판별 조건을 사람이 쓰지 않습니다. 사람은 정답이 붙은 자료를 준비하고, 모델은 자기 예측이 정답과 어긋난 정도를 보며 계산에 쓰는 수치를 고칩니다. 사람의 일이 “규칙 작성”에서 “기준을 정하고 자료에 정답을 붙이는 일”로 옮겨 갑니다.

보충 · 자료 밖 내용

규칙 기반 시스템은 지금도 쓰입니다. 금지어 필터, 형식 검사(이메일 주소·날짜), 법규처럼 근거를 설명해야 하는 판정이 대표적입니다. 실제 서비스는 규칙과 학습 모델을 함께 쓰는 경우가 많습니다. 그래서 p.49의 질문 “머신러닝을 사용하지 않는 인공지능도 있는가?”의 답은 “있다”입니다.

스팸 필터는 머신러닝이 대중적으로 쓰인 초기 사례로 자주 언급됩니다(예: 단어 출현 확률을 쓰는 나이브 베이즈 필터).

강의 포인트

학습자가 “AI는 다 학습한다”고 말하면, p.20의 오판 두 개를 보여 주고 “이 프로그램도 AI인가?”를 물어보세요. 규칙 기반도 AI의 한 방식이라는 점과, 학습 방식이 그 한계를 어떻게 다루는지를 한 번에 구분하게 됩니다.

03라벨 · 특징 · 모델 · 매개변수p.22–24

학습에 필요한 재료와 계산 구조를 나눠 봅니다. 네 용어는 “입력의 어느 부분인가, 계산의 어느 부분인가”로 구분하면 섞이지 않습니다.

입력 특징링크 1개 / 송금 요구 있음 / 알려진 발신자 아님
→
모델특징을 계산하는 구조 + 계산에 쓰는 수치(매개변수)
→
예측계산한 점수 → 분류 결과
⇄
라벨학습 중 예측과 비교할 정답: 스팸
라벨 · 라벨링 (p.22)
라벨은 학습 자료에 붙인 분류값, 라벨링은 정한 기준에 따라 라벨을 붙이는 작업입니다. 자료의 기준 예는 “신청한 안내인가, 원치 않는 광고·사기성 메일인가?”입니다(교육용 사례).
특징 (p.23)
메일을 계산할 수 있는 정보로 표현한 것입니다. “특징은 예측에 쓰는 정보, 라벨은 학습 중 예측과 비교할 값이다.” 특징은 입력 쪽, 라벨은 정답 쪽입니다.
모델 · 매개변수 (p.24)
모델은 입력을 받아 결과를 계산하는 구조이고, 매개변수는 “모델 안에서 계산에 사용하며, 학습으로 조정하는 수치”입니다. 구조는 그대로 두고 매개변수만 바뀌는 것이 학습입니다.

주의 · 라벨링 기준이 흔들리면

같은 종류의 메일에 사람마다 다른 라벨을 붙이면, 모델은 그 흔들림까지 배웁니다. 라벨링 전에 기준 문장과 경계 사례(예: 수강생이 신청한 유료 강좌 광고)를 먼저 정하는 이유입니다.

보충 · 자료 밖 내용

p.49는 “라벨 없이도 학습할 수 있는가?”를 묻습니다. 가능합니다. 정답 없이 비슷한 자료끼리 묶는 비지도 학습이 있고, 언어 모델의 사전학습처럼 원문 자체에서 목표를 만들어 학습하는 자기지도 학습도 있습니다. 후자는 오후 첫 구간 p.93(“다음 토큰 학습의 목표는 원문에서 얻는다”)에서 다룹니다.

04가중치 계산과 학습p.25–27

매개변수가 실제로 어떻게 결과를 바꾸는지 숫자로 따라갑니다. 수치는 모두 자료의 “설명용 모형”입니다.

자료 p.25 · 설명용 모형

스팸 점수 = 링크 × 0.2 + 송금 요구 × 0.1 − 알려진 발신자 × 0.6
점수 0.5 이상이면 스팸 · 0.2, 0.1, 0.6이 가중치

검증 · 자료의 계산을 다시 해 봄 일치

p.25 1×0.2 + 1×0.1 − 0×0.6 = 0.3 → 0.5 미만 → 일반 메일로 예측 p.27 송금 요구 가중치 0.1 → 0.7 1×0.2 + 1×0.7 − 0×0.6 = 0.9 → 0.5 이상 → 스팸으로 예측

두 값 모두 자료와 일치합니다. 라벨이 스팸이므로 조정 전에는 불일치, 조정 후에는 일치입니다.

현재 모델의 예측사기성 메일을 일반으로 예측
→
라벨과 비교올바른 분류는 스팸 · 오차 계산
→
매개변수 조정여러 자료의 오차가 줄어드는 방향으로
자료 p.26 · p.27

“학습 자료로 예측·비교·조정을 반복한다. 새 메일도 잘 분류하는지는 따로 확인한다.”

“한 자료에서 맞았다고 학습이 끝나는 것은 아니다.”

보충 · 자료 밖 내용

  • 자료는 0.1을 한 번에 0.7로 바꿨지만, 실제 학습은 보통 작은 폭의 조정을 수많은 자료에서 반복합니다. 조정 방향을 계산하는 대표적 방법이 경사하강법이고, 한 번에 움직이는 폭을 학습률이라고 합니다.
  • 한 메일에만 맞추면 다른 메일에서 틀릴 수 있습니다. 학습에 쓰지 않은 자료(검증·테스트 자료)로 따로 확인하는 이유입니다. 학습 자료에만 지나치게 맞춰진 상태를 과적합이라고 합니다.

강의 포인트 · 수치 하나 바꿔 보기

같은 메일이 알려진 발신자(1)에게서 왔다면? 조정 후 가중치로 0.2 + 0.7 − 0.6 = 0.3, 일반 메일로 예측됩니다. 가중치는 그대로인데 입력이 바뀌어 결과가 달라진 경우와, 입력은 그대로인데 가중치가 바뀌어 결과가 달라진 경우를 나란히 놓으면 학습과 추론의 차이가 바로 보입니다.

05학습과 추론p.28–29

오늘 하루를 관통하는 구분입니다. 두 과정에서 “무엇이 바뀌는가”만 기억하면 됩니다.

학습추론
하는 일자료와 목표로 오차를 계산새 입력을 모델에 전달
매개변수조정한다그대로 쓴다
결과학습된 모델이번 입력의 예측·응답
자료 p.28

“새 메일을 처리하는 일과 모델을 다시 학습시키는 일은 서로 다르다.”

주의 · “쓰면서 배운다”는 오해

서비스가 사용자 반응을 모아 나중에 모델을 다시 학습시키는 경우는 있습니다. 하지만 그것은 별도로 실행하는 학습 작업입니다. 질문 하나를 처리하는 추론 자체가 매개변수를 바꾸지는 않습니다.

보충 · 자료 밖 내용 용어

영어로는 학습 training, 추론 inference입니다. 오후 둘째 구간 p.123에서 ‘추론’이 “조건을 비교해 결론을 내는 문제 풀이(reasoning)”라는 다른 뜻으로도 쓰인다는 점을 다룹니다. 같은 한국어 단어가 두 뜻을 가지므로, 가르칠 때는 어느 뜻인지 먼저 밝히는 것이 좋습니다.

12핵심 정리

  • AI가 내놓는 결과는 분류·수치 예측·생성으로 나뉘고, 이 구분은 만드는 방법과 별개입니다.
  • 판별 기능은 사람이 규칙을 쓰거나, 정답이 붙은 자료로 학습해 만듭니다.
  • 모델은 계산 구조이고, 학습은 그 안의 매개변수(가중치)를 예측과 라벨의 오차가 줄도록 조정하는 일입니다.
  • 학습은 매개변수를 바꾸고, 추론은 그대로 씁니다. 오늘의 도착점인 “파일 제공 ≠ 학습”의 바탕입니다.
  • 사용자가 쓰는 것은 모델을 둘러싼 서비스이며, 도구·에이전트·자동화는 서비스 쪽 구성입니다.
