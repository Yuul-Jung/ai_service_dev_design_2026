01. 전체 기술 테크트리

이미지의 특징을 재사용하는 방법에서 출발해, 언어 모델의 학습 효율화와 로봇 행동 학습까지 확장합니다.

전이학습이란?

이미 배운 특징과 지식을 새로운 문제에 재사용하는 방법입니다. CIFAR-10에서는 사진 종류를 구별하도록 사전학습된 이미지 모델을 조정합니다.

LoRA가 왜 필요한가?

거대한 모델의 모든 가중치를 바꾸지 않고 작은 추가 행렬만 학습하여 메모리·저장 비용을 줄입니다. QLoRA는 양자화된 기본 모델 위에서 LoRA 학습을 진행하는 방식입니다.

RAG는 전이학습인가?

아닙니다. RAG(검색 증강 생성)는 문서를 검색해서 모델에 제공하며, 모델 가중치는 변경하지 않습니다. LoRA 학습과 함께 사용할 수 있습니다.

LLM만으로 로봇을 제어하나?

아닙니다. LLM은 명령을 해석하고, VLM은 시각 상황을 이해하고, VLA 또는 제어 계획기가 행동을 생성합니다. 실시간 제어와 안전 차단은 별도 계층이 담당합니다.

CH 01 · 전이학습

아는 것을 다시 쓰는 방법

핵심 질문: 고양이를 알아보는 CNN의 선·윤곽 검출 능력을 자동차 분류에도 쓸 수 있을까?

따라 하기: 같은 그림의 특징 추출기를 고정하거나 풀었을 때 학습 대상 계층을 색으로 구분한다.

검증: 고정한 계층의 가중치가 업데이트되지 않는지 확인한다.

CH 02 · CIFAR-10

ResNet-18 전이학습 비교

핵심 질문: 처음부터 학습한 모델과 ImageNet 가중치를 재사용한 모델은 무엇이 다른가?

따라 하기: 32×32 컬러 이미지 10종을 학습하며 사전학습 가중치에 맞게 Resize·Normalize 전처리를 적용한다.

검증: 동일 테스트셋 정확도와 학습 시간·과적합 정도를 비교한다.

CH 03 · 로컬 LLM

모델 실행과 평가의 출발점

핵심 질문: 언어 모델은 왜 사진 분류기보다 메모리를 많이 사용하는가?

따라 하기: 모델 파라미터 수·가중치 정밀도·문맥 길이에 따른 메모리 변화를 확인한다.

검증: 고정 질문 20개의 기본 모델 응답을 따로 저장한다.

CH 04 · LoRA

작은 추가 가중치 학습

핵심 질문: 수십억 개의 숫자를 전부 바꾸지 않고 답변 방식을 개선할 수 있을까?

따라 하기: 학습 가능한 어댑터 파라미터 수와 기본 모델 파라미터 수를 출력해 비교한다.

검증: 기본 가중치가 고정되어 있는지, 어댑터 파일이 저장됐는지 확인한다.

CH 05 · QLoRA

양자화와 학습의 구분

핵심 질문: 4비트 양자화가 학습을 대체하는가? 아니면 기본 모델 저장 부담을 줄이는가?

따라 하기: 동일 모델의 LoRA·QLoRA 학습 설정, 배치 크기, GPU 최대 메모리 사용량을 기록한다.

검증: 데이터 형식과 학습 라이브러리 호환성을 확인한다.

따라 하기: 올바른 모듈·실패 사례·수정 이유로 예제 데이터를 구성한다.

검증: 학습하지 않은 테스트 문제로 컴파일 가능성과 설명 정확도를 평가한다.

08. 첫 종합 과제 — 빨간 블록 이동

목표: 카메라 앞의 빨간 블록을 발견하고, PC의 구조화된 명령을 검증하여 저속 모터를 움직입니다. 로봇팔 집기까지는 후속 단계로 확장합니다.

01
카메라 인식

빨간 물체의 중심 좌표와 신뢰도를 측정합니다.

02
명령 해석

LLM은 자유 텍스트 대신 정해진 명령 집합으로 작업을 표현합니다.

03
제어 신호 검증

허용 범위·타임아웃·정지 조건을 별도로 검증합니다.

04
FPGA 구동

검증된 명령만 PWM과 모터 구동 신호로 변환합니다.

05
결과 확인

카메라·센서로 동작을 관찰하고 실패를 기록합니다.

명령 데이터 예시

{ "action": "MOVE_RIGHT", "speed_level": 1, "duration_ms": 200 }

설명용 예시 JSON입니다. 실장비에서는 별도의 메시지 스키마 검증, 속도 제한, 하드웨어 정지 회로가 필요합니다.

09. 진행 체크리스트
