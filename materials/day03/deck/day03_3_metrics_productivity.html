자료 p.85

기준선: 새 모델을 비교할 간단한 방법의 성능. 모두 “환불 아님”으로 예측하면 환불 아님 90건 = 90%. 환불 요청 10건은 하나도 찾지 못한다.

검증 · 아무것도 하지 않는 방법의 점수 일치

전부 “환불 아님”으로 예측 → 맞힌 수 90 ÷ 전체 100 = 90% 실제 환불 10건 중 찾은 수 0 → 재현율 0%

환불을 단 한 건도 찾지 못하는 방법이 정확도 90%를 받습니다. 그래서 새 모델의 점수를 보기 전에 기준선과 범주별 자료 수를 먼저 봅니다(p.103의 질문).

검증 · 모든 숫자를 혼동행렬에서 다시 계산 일치

TP(환불을 맞힘) = 8 FN(환불을 놓침) = 2 FP(환불 오탐) = 10 TN(일반을 맞힘) = 80 전체 = 8 + 2 + 10 + 80 = 100 ✓ 실제 환불 = 8 + 2 = 10 ✓ 환불로 예측 = 8 + 10 = 18 ✓ 정확도 = 88 ÷ 100 = 88% 재현율 = 8 ÷ 10 = 80% 정밀도 = 8 ÷ 18 = 44.44%

자료의 세 값이 모두 맞고, p.87의 점 그림(첫 줄 8+2, 둘째 줄 10, 나머지 80)과도 일치합니다. 점 하나는 문의 1건이며 위치는 실제 시간 순서가 아닌 이해를 돕기 위한 배열입니다(p.87). scikit-learn의 confusion_matrix·precision_score·recall_score·f1_score로도 같은 값(정확도 0.88, 재현율 0.80, 정밀도 0.4444, F1 0.5714)이 나왔습니다.

보충 · 자료 밖 내용 · 자주 함께 나오는 지표

F1 점수 = 2 × 정밀도 × 재현율 ÷ (정밀도 + 재현율) = 2 × 0.444 × 0.8 ÷ 1.244 ≈ 0.571 실제 환불이 아닌 것 중 환불로 잘못 알린 비율 (오탐률) = 10 ÷ 90 ≈ 11.1% 실제 환불이 아닌 것 중 맞힌 비율 (특이도) = 80 ÷ 90 ≈ 88.9%

F1은 정밀도와 재현율을 하나로 합친 값이고, 둘 중 낮은 쪽에 가깝게 나옵니다. 정밀도와 재현율의 분모가 다르다는 점(재현율은 실제 환불 10건, 정밀도는 예측한 18건)을 학습자가 가장 자주 혼동하니 분모를 먼저 짚어 주세요.

주의 · 지표 이름보다 분모를 기억하게 한다

“정밀도 = 환불이라고 알린 것 중 맞힌 비율”, “재현율 = 실제 환불 중 찾은 비율”처럼 문장으로 외우게 하세요. 영어 용어(precision, recall)는 이름만으로는 뜻이 떠오르지 않아서, 분모(알린 것 / 실제 있는 것)를 먼저 말하는 편이 오해가 적습니다.

04회귀의 평가 · 평균절대오차p.94–95

자료 p.95

평균절대오차 = (1 + 1 + 0) ÷ 3 ≈ 0.67시간

검증 · 오차를 그냥 평균하면 안 되는 이유 일치 반례 추가

부호를 두고 평균 (예측 − 실제): A +1, B −1, C 0 → (+1 − 1 + 0) ÷ 3 = 0시간 절댓값으로 평균(MAE): (1 + 1 + 0) ÷ 3 = 0.667시간 ✓

부호를 두고 평균하면 +1과 −1이 상쇄되어 0시간, 즉 “완벽”으로 보입니다. 실제로는 A와 B 두 건이 1시간씩 빗나갔습니다. 그래서 크기(절댓값)로 평균합니다. 단위는 시간으로, 평균 약 40분 빗나갔다고 말할 수 있어서 안내 문구에 바로 쓸 수 있습니다.

검증 · 평균이 숨기는 것 (p.103의 질문) 추가 계산

오차 (1, 1, 0)시간: MAE = 0.667 RMSE(제곱 평균의 제곱근) = √(2 ÷ 3) = 0.816 오차 (2, 0, 0)시간: MAE = 0.667 RMSE = √(4 ÷ 3) = 1.155

두 경우 모두 MAE는 0.67시간이지만, 두 번째는 한 건이 2시간이나 빗나갔습니다. 평균은 이런 큰 오차를 숨깁니다. 큰 오차를 더 무겁게 보려면 제곱해서 평균하는 방법(RMSE)이 있고, 이때 두 경우의 값이 0.82와 1.16으로 갈립니다. 어느 쪽을 쓸지도 “한 번의 큰 오차가 얼마나 나쁜가”라는 업무 판단입니다.

09핵심 정리

  • 평가 자료(어떤 입력에서)와 평가지표(무엇을 세는가)는 서로 다른 질문이고, 지표는 분모로 구별합니다.

  • 정확도·재현율·정밀도는 같은 8·2·10·80에서 88% · 80% · 44.4%로 달라지고, 무엇이 더 중요한지는 오류의 영향이 정합니다.

  • 모델의 점수와 사람의 과제 성과, 그리고 스스로 이해한 것은 각각 다른 측정입니다. 완료율이 높다고 정답률이 높은 것은 아닙니다.
