새 자료에서도 잘하는가

일반화, 학습·검증·테스트 자료의 역할, 과적합과 학습 곡선, 분포 변화, 데이터 누수를 문의 처리시간 예측 사례로 정리합니다. 검증과 테스트를 나누는 이유는 시뮬레이션으로 직접 확인했습니다.

쪽 p.54–80시뮬레이션 검증 59.2% ↔ 테스트 50.1%학습 곡선 그림 대조누수 사례 계산 일치

일반화Generalization

학습하지 않은 새 자료에서도 성능이 유지되는 정도입니다. 학습 자료의 점수는 이를 대신하지 못하므로 학습에 쓰지 않은 자료로 평가합니다(p.55–56).

데이터 누수Data leakage

실제 예측 때는 없는 정보가 입력에 들어가거나, 평가할 자료가 학습에 미리 섞이는 문제입니다. 점수가 낮아서가 아니라 너무 좋아서 드러납니다(p.70).

학습은 조정, 검증은 선택, 테스트는 최종 평가입니다. 선택이 검증 점수를 부풀리므로 테스트 자료를 따로 남기고, 점수가 낮은 이유가 과적합·누수·분포 변화 중 무엇인지는 결과만으로 정할 수 없습니다.

“검증 결과는 선택에 영향을 준다. 테스트 자료는 그 선택으로부터 따로 남겨 둔다.”

검증 · 왜 검증으로 골랐는데 테스트가 또 필요한가 (시뮬레이션) 자료의 주장 확인 추가 계산

p.59의 이유를 숫자로 확인하기 위해 작성자가 시뮬레이션을 했습니다. 실제 정확도가 모두 50%인 모델 50개(즉 모두 동전 던지기 수준)를 검증 자료 150건으로 평가하고, 검증 점수가 가장 높은 모델을 고른 뒤 따로 둔 테스트 자료 150건으로 다시 평가했습니다. 이를 2,000번 반복한 평균입니다. 같은 설정의 해석 해(이항분포로 구한 “50개 최댓값의 기댓값”)는 59.16%이고, 2만 번으로 다시 돌린 결과는 검증 59.2% · 테스트 50.0%로 일치했습니다.

측정평균 정확도
모델이 1개일 때의 검증 점수50.0% (기댓값)
50개 중 검증 점수가 가장 높은 모델의 검증 점수59.2%
그 모델의 테스트 점수50.1%

모두 50%짜리 모델인데도 “가장 잘 나온 것”을 고르면 검증 점수는 약 9%p 부풀려집니다. 부풀려진 점수를 최종 성능으로 보고하면 틀리고, 선택에 쓰지 않은 테스트 자료에서는 원래 수준(약 50%)이 드러납니다. 시뮬레이션은 작성자가 직접 돌린 것이며 난수 시드를 고정했습니다. 모델을 많이 비교할수록, 설정을 많이 바꿔 볼수록 이 부풀림이 커집니다.

강의 포인트

학습자에게 “시험 문제를 보고 공부 방법을 고른 뒤, 같은 시험으로 실력을 말하면?”을 물어보세요. 검증과 테스트를 나누는 이유가 “선택 과정이 이미 그 자료를 본 것”이라는 한 문장으로 정리됩니다.

자료는 “관찰한 사실”과 “가능한 해석”을 따로 적었습니다. 학습 손실과 검증 손실의 격차가 커졌다는 것은 사실이고, 과적합이라는 것은 해석입니다. 검증 자료가 학습 자료와 성격이 다르거나(분포 변화, 05절), 검증 자료에 문제가 있어도 같은 곡선이 나올 수 있습니다. 수업에서 “곡선이 벌어졌으니 과적합”이라고 한 줄로 가르치지 말고 이 세 칸을 그대로 쓰세요.

04과적합을 줄이는 방법 · 조기 종료와 정규화p.66–67

방법 (p.66)하는 일
조기 종료검증 손실이 가장 작았던 시점의 모델을 선택 (앞 곡선에서는 반복 3)
정규화예측 오차만 줄이는 대신 과도한 맞춤에 제약을 추가 (예: 큰 가중치에 벌점)
자료 p.67

L2 정규화: 학습 목표 = 예측 손실 + λ × 가중치 제곱합. 오차 감소와 가중치 증가를 함께 고려한다. λ는 벌점의 강도를 정하는 값이다. 너무 크면 필요한 관계도 못 배울 수 있다. “벌점의 강도는 검증 자료로 선택합니다. 작은 가중치가 항상 좋은 것은 아닙니다.”

검증 · 벌점이 목표를 어떻게 바꾸는가 (추가 계산 · 설명용) 계산 확인

가중치 w = [3, −4], 예측 손실 0.5, λ = 0.1 가중치 제곱합 = 3² + (−4)² = 9 + 16 = 25 벌점 = λ × 25 = 2.5 학습 목표 = 0.5 + 2.5 = 3.0 같은 예측 손실이라도 가중치가 w = [1, −1]이면 제곱합 2 → 벌점 0.2 → 목표 0.7

같은 손실이어도 큰 가중치를 쓰면 목표 값이 커져서, 오차를 조금 더 줄이려고 가중치를 키우는 선택이 불리해집니다. λ를 0으로 하면 벌점이 사라져 오차만 보게 되고, λ를 너무 키우면 가중치를 거의 0으로 눌러 필요한 관계도 못 배웁니다(과소적합). 그래서 λ는 검증 자료로 고른다고 자료가 말합니다.

보충 · 자료 밖 내용

L2 정규화는 가중치를 매번 조금씩 줄이는 ‘가중치 감쇠’와 단순한 최적화 방법에서는 같은 효과를 냅니다. 다만 최근 쓰이는 일부 최적화 알고리즘에서는 둘이 다르게 동작해서 가중치 감쇠를 분리해 쓰는 방식이 따로 나왔습니다(AdamW). PyTorch 소스에서 Adam의 weight_decay는 “L2 penalty”로 설명되고, AdamW는 분리된(decoupled) 가중치 감쇠를 쓰는 것을 확인했습니다. 수업에서는 “큰 가중치에 벌점”까지만 가르치고, 이 구분은 질문이 나올 때 답하면 충분합니다.

09핵심 정리

  • 학습에 쓴 자료의 점수는 새 자료의 성능을 대신하지 못하므로 학습에 넣지 않은 자료로 평가합니다.
  • 학습은 조정, 검증은 선택, 테스트는 최종 평가입니다. 선택이 검증 점수를 부풀리므로(시뮬레이션: 50% 모델 50개 중 최고가 59.2%) 테스트를 따로 남깁니다.
  • 분할은 비율보다 분리 조건(중복 제거, 사람 단위, 시간 순서)이 중요합니다.
  • 학습 곡선에서 사실(두 손실의 방향)과 해석(과적합)을 구분하고, 원인에 맞춰 조기 종료·정규화·자료 보강을 고릅니다.
  • 데이터 누수는 실제 예측 때 없는 정보나 평가 자료의 혼입이며, 점수가 낮아서가 아니라 너무 좋아서 드러납니다.
