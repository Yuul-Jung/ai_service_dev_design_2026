1. 비교 기준과 판정 원칙

순위는 시장점유율이 아닌 교육자료 배포 및 AI 서비스 개발에 대한 추천 우선순위입니다. 아래 서비스는 공식 안내 페이지가 확인되는 후보로, 무료 사용량·가입 가능 여부·상업적 사용·결제 카드 등록은 가입 직전 반드시 재확인해야 합니다.

무료 ≠ 무제한 ≠ 서버 상시 실행
정적 호스팅, 서버리스 함수, 프로세스가 계속 실행되는 가상 서버는 서로 다른 제품입니다. 무료 체험 크레딧은 영구 무료와 구분하며, 확인되지 않은 수치는 표기하지 않습니다.

원본 참고 글: 무료 호스팅 TOP 10 (외부 블로그). 비교표는 원문을 복제하지 않고 공식 사이트 기반으로 재구성했습니다.

3. 적대적 검증: 이전 설명에서 수정한 핵심 오류

Oracle Cloud A1

무료 ARM 인스턴스의 공식 안내는 월 1,500 OCPU 시간·9,000GB 시간으로, 상시 이용 기준 합산 2 OCPU·12GB RAM 상당입니다. 기존 4 OCPU·24GB 표기는 폐기합니다.

공식 문서
000webhost 종료

2024년 7월 신규 가입 중지, 2024년 10월 14일 종료. 운영 중인 무료 서비스 목록에서는 제외합니다.

공식 공지
Vercel Hobby

무료 요금제는 개인·비상업적 사용으로 제한됩니다. 업무·상업적 AI 서비스 배포를 추천하지 않습니다.

공식 문서
GitHub Pages

배포 사이트 최대 1GB, 월 100GB 대역폭은 소프트 제한입니다. 서버 측 Python 프로세스는 직접 실행할 수 없습니다.

공식 문서
Cloudflare Pages

무료 월 500회 빌드, 최대 20,000개 파일, 파일당 25MiB 제한. Functions 요청은 Workers 요금제 한도로 따로 계산됩니다.

공식 문서
DigitalOcean·Railway

DigitalOcean은 정적 앱 3개까지만 무료 대상입니다. Railway 등 크레딧형 서비스는 월별 한도·체험 크레딧·초과 청구를 따로 검토해야 하며 이 표에서 영구 무료 서버로 확정하지 않았습니다.

4. 선택 가이드: 프로젝트에 맞는 배포 방식

HTML 교재·SVG·이미지

GitHub Pages → Cloudflare Pages
정적 자료 및 소스 이력 중심. 기존 GitHub 저장소와 목차 유지.

React·Next.js 프런트엔드

Netlify / Vercel / Cloudflare
개인·상업용 정책과 빌드·함수 한도를 먼저 대조.

FastAPI·백엔드 연계

Render(실습) / 별도 Ubuntu 서버
무료 인스턴스 유휴 중지·데이터 영속성 제한 주의.

GitHub 저장소
HTML / CSS / JS→GitHub Pages
공개 학습자료↔FastAPI 서버
인증 / API↔별도 연산 서버
LLM / Elasticsearch / KiCad

GitHub Pages가 서버 API를 호출할 수는 있지만, 인증 토큰이나 API 키를 정적 HTML·JavaScript에 노출하면 안 됩니다. 외부 공개 API는 인증·접근 제어·HTTPS·CORS·속도 제한을 고려해야 합니다. GPU 모델 추론을 무료 정적 호스팅에서 직접 실행할 수 있다고 가정하지 않습니다.

5. 게시 전 점검

  1. 계정·리전에서 무료 가입과 자원 개설이 가능한지 확인
  2. 상업적 사용 허용·카드 등록·자동 청구·초과 과금 규칙 확인
  3. 월 빌드·대역폭·파일 크기·함수 실행·유휴 중지 조건 확인
  4. DB 백업·지속 저장소·도메인·HTTPS·로그 보존 확인
  5. 비밀키를 GitHub 저장소·공개 HTML에 포함하지 않도록 검사

문서 갱신 기준: 2026-11-14. 요금·제품 정책은 수시로 변경되므로 링크된 공식 문서를 우선합니다. 특정 서비스의 무료 정책을 확인하지 못한 부분은 수치로 단정하지 않았습니다.
