오전 — AI는 무엇을 보고 배우는가

지도·비지도·자기지도·강화학습을 ‘어떤 정보로 배우는가’의 축으로 묶고, LLM의 사전학습·미세조정·선호학습과 신경망·Transformer의 계산 구조를 문의 분류 예로 따라갑니다. 자료의 계산을 모두 다시 해 보고 반례를 더했습니다.

  • 자기지도학습 Self-supervised learning 사람이 붙인 정답 없이 자료 자체에서 학습 목표를 만듭니다. 글의 앞부분을 입력으로, 실제 이어진 다음 부분을 목표로 삼는 것이 언어 모델의 대표적인 목표입니다(p.17).
  • 비선형 변환 Nonlinearity · ReLU 곱하고 더하기만 반복하면 여러 층도 한 층과 같아집니다. 사이에 비선형 변환이 들어가야 직선 하나로 표현할 수 없는 관계를 배웁니다(p.40).

오후 첫 구간 — 새 자료에서도 잘하는가

일반화, 학습·검증·테스트 자료의 역할, 과적합과 학습 곡선, 분포 변화, 데이터 누수를 문의 처리시간 예측 사례로 정리합니다. 검증과 테스트를 나누는 이유는 시뮬레이션으로 직접 확인했습니다.

  • 일반화 Generalization 학습하지 않은 새 자료에서도 성능이 유지되는 정도입니다. 학습 자료의 점수는 이를 대신하지 못하므로 학습에 쓰지 않은 자료로 평가합니다(p.55–56).
  • 데이터 누수 Data leakage 실제 예측 때는 없는 정보가 입력에 들어가거나, 평가할 자료가 학습에 미리 섞이는 문제입니다. 점수가 낮아서가 아니라 너무 좋아서 드러납니다(p.70).

오후 둘째 구간 — 잘한다는 숫자는 무엇을 뜻하는가

기준선과 클래스 불균형, 혼동행렬에서 나오는 정확도·재현율·정밀도, 회귀의 평균절대오차를 같은 100건으로 계산하고, AI를 쓰는 사람의 과제 성과를 보여 주는 컨설턴트 실험을 한계와 함께 읽습니다.

  • 재현율과 정밀도 Recall · Precision 재현율은 실제 환불 중 찾은 비율(8÷10), 정밀도는 환불이라고 알린 것 중 맞힌 비율(8÷18)입니다. 분모가 다르다는 점이 핵심입니다(p.89–91).
  • 기준선 Baseline 새 모델을 비교할 간단한 방법의 성능입니다. 모두 ‘환불 아님’으로 예측해도 정확도 90%가 나오므로 점수를 보기 전에 기준선을 봅니다(p.85).

마지막 구간 — 배운 내용을 교육자료로 정리하기

오늘 배운 것 중 하나를 골라 대상에게 설명할 자료로 만드는 과정을 정리하고, 세 주제의 수업 뼈대, AI 초안의 오류 찾기 연습, 3일차 전체의 흔한 오해 14가지와 보완 자료를 더했습니다.

  • 설명할 관계 Relation to explain 개념의 정의가 아니라 개념 사이의 관계(무엇으로 무엇을 조정하는가, 곡선에서 보이는 사실은 무엇인가, 무엇을 무엇으로 나누는가)를 가르칠 내용으로 정합니다(p.107).
  • 새 사례 확인 질문 Transfer question 조건 하나를 바꾼 새 상황을 주고, 답과 이유가 달라졌는지로 이해를 판단합니다. 설명이 매끄러운지는 이해의 증거가 아닙니다.

보상

예: 보행 로봇이 넘어지지 않고 앞으로 이동하도록 학습. 행동의 결과(넘어짐 / 균형을 유지하며 이동)에 더 높은 평가를 부여하고, 여러 시도의 보상을 이용해 상황별 행동 선택 방식(정책)을 조정한다. “정답 동작을 그대로 따라 하는 학습과 달리, 행동한 결과를 평가에 사용한다.”

응답 A: 5 정답 1
응답 B: 6 오답 0

“보상을 비교해 응답 생성 방식을 학습으로 조정”합니다. 자료는 이것이 “검증 가능한 정답 보상의 개념도이고 실제 모델의 학습 기록은 아니다”라고 밝힙니다.

보충 · 자료 밖 내용

  • 한 번에 하나가 아니라 여러 개를 비교한다. 같은 문제에 여러 응답을 만들어 보상을 비교하고, 평균보다 보상이 높았던 응답의 생성 방식을 강화하는 방법(그룹 상대 정책 최적화, GRPO)이 있습니다. TRL 라이브러리에 이 방법의 트레이너(GRPOTrainer)가 제공되는 것은 소스에서 확인했고, 수학·코드 문제에 쓰인다는 설명은 논문 원문을 열 수 없어 작성자 지식으로 둡니다. 위 표의 A와 B를 비교하는 구조가 그 단순화입니다.
  • 보상은 확인할 수 있는 과제에서 쓰기 쉽다. 수학 정답이나 코드의 테스트 통과처럼 맞고 틀림을 확인할 수 있으면 보상이 명확합니다. 글쓰기처럼 좋고 나쁨이 주관적인 과제는 사람의 선호를 이용한 보상(08절)이 필요합니다.

주의 · 보상은 설계한 만큼만 평가한다

보상을 잘못 설계하면 모델이 보상을 높이는 편법을 배울 수 있다는 보고가 많습니다(작성자 지식). 예를 들어 “답이 길수록 높은 점수”라는 보상은 쓸데없이 긴 답을 낳습니다. 이 문장은 오후의 “점수가 높다고 목적에 맞는 것은 아니다”(평가지표)와 같은 이야기라서, 오전에 미리 던져 두기 좋습니다.

왜 비선형 변환이 필요한가 (p.40)

자료 p.40

곱하고 더하기만 반복하면 여러 층도 하나의 직선 관계로 합칠 수 있다. ReLU(음수는 0, 양수는 그대로)처럼 비선형 변환을 함께 쓰면 하나의 직선으로 나타낼 수 없는 패턴을 표현할 수 있다.

검증 · 층을 쌓아도 직선이라는 말을 숫자로 확인 (추가 계산) 〔자료의 주장 확인〕

text
입력 x = [1, −2]
1층 W1 = [[1, 1], [1, −1]]  → h = W1·x = [−1, 3]
2층 W2 = [1, 1]             → y = W2·h = 2

두 층을 하나로 합치면 W2·W1 = [2, 0] → y = 2·1 + 0·(−2) = 2   (같음 ✓)
중간에 ReLU를 넣으면 h = [0, 3] → y = 3                       (달라짐)

선형 층만 쌓으면 한 층으로 합쳐져서 층을 늘린 의미가 없고, 사이에 비선형 변환이 들어가야 층마다 다른 일을 할 수 있습니다. 이 한 줄이 p.50 질문 “여러 계산층을 쓰는 이유”와 2일차 보충의 답입니다.

text
ReLU(x) + ReLU(−x) = |x|     x = −2, 0, 2 → 2, 0, 2
직선 f(x) = ax + b 로 세 점 (−2, 2), (0, 0), (2, 2)를 지나게 할 수 있을까?
  f(0) = 0 이므로 b = 0, f(2) = 2 이므로 a = 1 → f(−2) = −2 ≠ 2   → 불가능

ReLU 두 개로 만든 |x|는 직선 하나로는 표현할 수 없는 모양입니다. 자료의 “직선 하나로 표현할 수 없는 관계”의 가장 작은 예입니다.

주의 · 엄밀히 말하면 ‘직선’은 편향이 있는 직선

편향이 있으면 선형 층의 합성은 원점을 지나지 않는 직선(수학에서는 아핀 변환)이 됩니다. p.40의 왼쪽 그림도 원점을 지나지 않는 선입니다. 수업에서는 “직선 하나로 합쳐진다”로 충분하지만, 학습자가 “편향이 있으면 비선형 아닌가요?”라고 물으면 위 설명으로 답하세요.

L2 정규화: 학습 목표 = 예측 손실 + λ × 가중치 제곱합. 오차 감소와 가중치 증가를 함께 고려한다. λ는 벌점의 강도를 정하는 값이다. 너무 크면 필요한 관계도 못 배울 수 있다. “벌점의 강도는 검증 자료로 선택합니다. 작은 가중치가 항상 좋은 것은 아닙니다.”

검증 · 벌점이 목표를 어떻게 바꾸는가 (추가 계산 · 설명용) 〔계산 확인〕

text
가중치 w = [3, −4], 예측 손실 0.5, λ = 0.1
가중치 제곱합 = 3² + (−4)² = 9 + 16 = 25
벌점 = λ × 25 = 2.5
학습 목표 = 0.5 + 2.5 = 3.0

같은 예측 손실이라도 가중치가 w = [1, −1]이면 제곱합 2 → 벌점 0.2 → 목표 0.7

같은 손실이어도 큰 가중치를 쓰면 목표 값이 커져서, 오차를 조금 더 줄이려고 가중치를 키우는 선택이 불리해집니다. λ를 0으로 하면 벌점이 사라져 오차만 보게 되고, λ를 너무 키우면 가중치를 거의 0으로 눌러 필요한 관계도 못 배웁니다(과소적합). 그래서 λ는 검증 자료로 고른다고 자료가 말합니다.

text
부호를 두고 평균 (예측 − 실제):  A +1, B −1, C 0 → (+1 − 1 + 0) ÷ 3 = 0시간
절댓값으로 평균(MAE):             (1 + 1 + 0) ÷ 3 = 0.667시간 ✓

부호를 두고 평균하면 +1과 −1이 상쇄되어 0시간, 즉 “완벽”으로 보입니다. 실제로는 A와 B 두 건이 1시간씩 빗나갔습니다. 그래서 크기(절댓값)로 평균합니다. 단위는 시간으로, 평균 약 40분 빗나갔다고 말할 수 있어서 안내 문구에 바로 쓸 수 있습니다.

검증 · 평균이 숨기는 것 (p.103의 질문) 〔추가 계산〕

text
오차 (1, 1, 0)시간: MAE = 0.667   RMSE(제곱 평균의 제곱근) = √(2 ÷ 3) = 0.816
오차 (2, 0, 0)시간: MAE = 0.667   RMSE = √(4 ÷ 3) = 1.155

두 경우 모두 MAE는 0.67시간이지만, 두 번째는 한 건이 2시간이나 빗나갔습니다. 평균은 이런 큰 오차를 숨깁니다. 큰 오차를 더 무겁게 보려면 제곱해서 평균하는 방법(RMSE)이 있고, 이때 두 경우의 값이 0.82와 1.16으로 갈립니다. 어느 쪽을 쓸지도 “한 번의 큰 오차가 얼마나 나쁜가”라는 업무 판단입니다.

38핵심 정리

오전

  • 학습 방법(어떤 정보로 배우는가)과 계산 구조(어떻게 계산하는가)와 평가(새 자료에서 얼마나 잘하는가)는 서로 다른 세 질문입니다.
  • 지도학습은 입력과 목표값의 관계, 비지도학습은 정답 없이 구조, 자기지도학습은 자료 자체에서 만든 목표, 강화학습은 행동의 결과를 평가한 보상으로 배웁니다.
  • LLM은 사전학습(자기지도) → 지도 미세조정(시범 답) → 선호·보상 반영으로 배우고, 같은 Transformer 구조에서 학습 자료와 목표만 바뀝니다.
  • 대화에서 고쳐 주는 것은 문맥이고, 모델이 학습하려면 별도의 학습 절차로 매개변수를 조정해야 합니다.
  • 층을 쌓아도 비선형 변환이 없으면 한 층과 같고, 학습은 순전파 → 역전파 → 최적화 순으로 가중치를 바꿉니다.

오후 첫 구간

  • 학습에 쓴 자료의 점수는 새 자료의 성능을 대신하지 못하므로 학습에 넣지 않은 자료로 평가합니다.
  • 학습은 조정, 검증은 선택, 테스트는 최종 평가입니다. 선택이 검증 점수를 부풀리므로(시뮬레이션: 50% 모델 50개 중 최고가 59.2%) 테스트를 따로 남깁니다.
  • 분할은 비율보다 분리 조건(중복 제거, 사람 단위, 시간 순서)이 중요합니다.
  • 학습 곡선에서 사실(두 손실의 방향)과 해석(과적합)을 구분하고, 원인에 맞춰 조기 종료·정규화·자료 보강을 고릅니다.
  • 데이터 누수는 실제 예측 때 없는 정보나 평가 자료의 혼입이며, 점수가 낮아서가 아니라 너무 좋아서 드러납니다.

오후 둘째 구간

  • 평가 자료(어떤 입력에서)와 평가지표(무엇을 세는가)는 서로 다른 질문이고, 지표는 분모로 구별합니다.
  • 범주 수가 불균형하면 기준선을 먼저 봅니다. 모두 “아님”도 정확도 90%가 나옵니다.
  • 정확도·재현율·정밀도는 같은 8·2·10·80에서 88% · 80% · 44.4%로 달라지고, 무엇이 더 중요한지는 오류의 영향이 정합니다.
  • 회귀는 오차의 크기로 평가하며, 부호를 두고 평균하면 상쇄되고 평균은 큰 오차를 숨깁니다.
  • 모델의 점수와 사람의 과제 성과, 그리고 스스로 이해한 것은 각각 다른 측정입니다. 완료율이 높다고 정답률이 높은 것은 아닙니다.

마지막 구간

  • 교육자료는 대상이 이미 아는 것에서 출발해, 한 가지 관계를 설명하도록 만듭니다.
  • AI와 공부할 때는 내 설명을 먼저 쓰고, 빠진 전제·다른 예·새 사례를 요청합니다.
  • AI 초안은 문장이 자연스러워도 숫자·출처·관계가 틀릴 수 있어서 직접 계산하고 원문을 확인합니다.
  • 설명의 점검은 용어·관계·그림과 수치·관찰과 해석·전체 설명 다섯 가지로 합니다.
  • 이해는 설명이 매끄러운지가 아니라 새 사례의 답이 달라졌는지로 확인합니다.
